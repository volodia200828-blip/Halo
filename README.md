# ⭕ Halo — Інтерактивне кругове меню та утиліта продуктивності

**Halo** — це сучасна високопродуктивна настільна утиліта для Windows (.NET 9 / WPF), яка виводить взаємодію з файлами на новий рівень за допомогою інтерактивного радіального (кругового) меню.

---

## 🌟 Ключові можливості

### 1. 🎯 Інтерактивне радіальне меню
* **Автоматична адаптація до файлу**: меню розуміє контекст (зображення, відео, аудіо, документ, папка) і пропонує релевантні сектори.
* **Плавний преміальний UI/UX**: векторні пелюстки секторів, неонове підсвічування, анімації масштабування (Spring / BackEase) та темна/світла теми.
* **Центральний хаб**: відображає мініатюру, розмір і назву вибраного файлу.
* **Drag-and-Drop підтримка**: скиньте файл у центр або прямо на екран для миттєвого відкриття дій.

### 2. 🎛️ Повна кастомізація (Меню налаштувань)
* **Керування діями**: вмикайте або вимикайте будь-яку функцію одним перемикачем.
* **Зміна порядку секторів**: переміщуйте сектори вгору/вниз (▲/▼), щоб розташувати улюблені інструменти під потрібними кутами.
* **Конструктор макросів**: створюйте власні дії та консольні команди із системною підстановкою `%FILE%` та `%DIR%`.
* **Налаштування візуалу**: регулювання радіуса меню (130–230 px), відображення підписів, автозакриття після кліку.

### 3. 🖼️ Вбудовані двигуни обробки
* **Конвертація**: миттєве перетворення у WebP, PNG, JPG (на базі SkiaSharp).
* **Редагування**: пропорційна зміна розміру (50%), розумне стиснення ваги файлу, монохромний чорно-білий арт-фільтр.
* **Системні дії**: швидке копіювання абсолютного шляху, відкриття термінала PowerShell у папці файлу, фокусування в Провіднику.

### 4. 📌 Поличка файлів (Shelf Pinboard)
* Тимчасовий плаваючий віджет для закріплення важливих файлів.
* Підтримує перетягування закріплених файлів у будь-яку зовнішню програму чи браузер.

### 5. 📂 Гарячі папки (Автоматизація)
* Відстежує нові файли у вказаних каталогах (наприклад, `Downloads` або `Screenshots`).
* Автоматично та непомітно застосовує призначені правила (наприклад, автоконвертація у WebP).

## 🚀 Швидкий запуск та розробка

### Вимоги
* Windows 10 / 11
* .NET 9 SDK (або .NET 10)

### Збірка та запуск

```bash
# Відновити залежності та зібрати рішення
dotnet build Halo.slnx

# Запустити додаток
dotnet run --project Halo.App/Halo.App.csproj

# Запустити автоматичні тести
dotnet test
```

### Гарячі клавіші за замовчуванням
* **Alt + Space** — відкрити Halo навколо активного виділеного файлу у Windows Explorer або навколо курсора.
* **Esc** — закрити радіальне меню.
