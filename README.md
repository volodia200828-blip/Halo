# HALO

**Робочий простір для миттєвої взаємодії з файлами.**

Нативний C++, плавні анімації, глибока інтеграція з Windows та повна кастомізація під ваші щоденні завдання.

## Про проєкт

Halo — це сучасна високопродуктивна настільна утиліта, яка виводить взаємодію з файлами на новий рівень. Замість того, щоб відкривати окремі важкі програми для базових завдань, ви використовуєте єдиний інтерактивний хаб. Радіальне (кругове) меню з'являється поверх усіх вікон, адаптується до типу вибраного файлу та пропонує релевантні інструменти.

Інтерфейс побудований з акцентом на преміальний UI/UX: плавні розкриття на фізиці пружин (Spring / BackEase), неонове підсвічування векторних пелюсток секторів та підтримка глибоко налаштовуваної темної і світлої тем. Додаток не перевантажує систему, оскільки написаний на нативному C++.

## Встановлення

Додаток поширюється як у вигляді відкритого вихідного коду, так і у форматі готових зібраних файлів. На [сторінці релізів](https://github.com/volodia200828-blip/Halo/releases) доступні:

* **Halo-Setup.exe** — зручний інсталятор. Автоматично створює ярлики в меню «Пуск», налаштовує автозапуск (за бажанням) та підтримує чисте видалення через стандартні параметри Windows.
* **Halo-win-x64.zip** — портативна (переносима) версія. Не потребує інсталяції: просто розпакуйте архів у будь-яку зручну папку та запустіть `Halo.exe`.
* **SHA256SUMS** — файл із контрольними сумами для перевірки цілісності та безпеки завантажених файлів.

**Системні вимоги:** Windows 10 (1809 або новіша) чи Windows 11, архітектура x64. Оскільки програма повністю скомпільована, вам не потрібно встановлювати Python, .NET чи мати активні API-акаунти. Усі необхідні бібліотеки Qt та C++ вже вшиті в дистрибутив.

## Ключові можливості

| Категорія | Функції та інструменти | Деталі реалізації |
| :--- | :--- | :--- |
| **Файлові операції** | ZIP, PDF, OCR, Медіа-кліпи | Миттєве пакування файлів у архіви, пряма конвертація фотографій і документів у PDF, вилучення тексту із зображень (OCR) та швидка обрізка відео без відкриття сторонніх редакторів. |
| **Інтерфейс та Хаб** | Адаптивне радіальне меню | Меню автоматично змінює контекст (пропонуючи різні дії для відео, аудіо, документів чи папок). Підтримка глобального Drag-and-Drop прямо на екран для миттєвого відкриття дії. |
| **Кастомізація** | Конструктор та візуал | Можливість створення власних дій та макросів через консольні команди із системною підстановкою `%FILE%` та `%DIR%`. Гнучке налаштування радіуса меню (130–230 px), порядку секторів та поведінки автозакриття. |
| **Автоматизація** | Відстеження директорій | Фоновий моніторинг вибраних локальних папок. Дозволяє налаштувати автоматичні правила для сортування, переміщення або обробки нових файлів у реальному часі. |

## Управління та поведінка

1. **Фонова робота:** Після запуску Halo згортається в системний трей і працює абсолютно непомітно, очікуючи на ваші дії.
2. **Швидкий виклик:** Натисніть глобальну комбінацію `Alt + Space` (можна перепризначити), щоб миттєво викликати робочий простір поверх ігор, повноекранного відео чи робочих програм.
3. **Взаємодія:** Перетягніть будь-який файл у центральну Drop-зону. Кругове меню миттєво розгорнеться, пропонуючи доступні інструменти. Центральний хаб відобразить мініатюру, розмір та точну назву вибраного об'єкта.
4. **Керування налаштуваннями:** Клікніть правою кнопкою миші по іконці в треї, щоб відкрити панель налаштувань. Усі зміни (від зміни порядку секторів до редагування макросів) застосовуються одразу, без необхідності перезапускати програму.
